Method

Work down the list. Each step checks itself against the live data; you can redo any step.

    Method

    cm²

    Edits change the orange preview line instantly. They reach the sensor only when you push them (Board tab). A blue • marks values that differ from the board.

    Let an optimiser search for the settings that best match the ground truth over the last few seconds of data.

    Settings it may change

    It fits on the first 70 % of the window and checks the result on the last 30 % (holdout). If holdout MSE does not drop, the fit is overfitting: don't push it.

    Data source
    This page is running its own simulator. To use the real sensor and pitot, run python -m calib serve in calibration/ and open the page it prints (http://localhost:8765). Every calibration script is then driven from here.
    Past recordings
    Send to the sensor

    Sends SET for each setting, then GET to confirm. The load-cell zero is never pushed, so a push cannot undo a TARE.

    Simulator

    Stands in for the tunnel until hardware is connected: a fan with spin-up lag, a noisy pitot, a cup rotor with inertia and a ringing drag plate. Run python -m calib serve for the real streams.

    Records every 200 Hz sample with ground truth, the PC preview, the board output and the settings in force. Each change of settings starts a new segment, scored against ground truth so you can see what each change did.
